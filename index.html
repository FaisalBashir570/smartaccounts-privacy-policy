Privacy Policy

Last Updated: August 2026

Faisal PSP Labs ("we", "us", or "our") developed and operates SmartAccounts, an offline-first Android application designed for customer accounts, ledger and business record management.

This Privacy Policy explains what information SmartAccounts handles, how that information is stored and used, and how optional backup services work.

1. Information We Handle

Depending on how the application is used, SmartAccounts may handle the following information:

  • Customer names and account information.
  • Ledger and transaction records.
  • Business and account management information.
  • User account information required for application access.
  • Contact information such as mobile number, WhatsApp number and email address when provided.
  • Country, province, city and address information when provided.
  • Application settings and preferences.
  • Backup information when the user chooses to create or restore a backup.

2. Local Storage and Offline-First Operation

SmartAccounts is designed as an offline-first application. Customer accounts, ledger records, transactions and other business records are primarily stored locally on the user's Android device using the application's local database.

SmartAccounts does not automatically upload customer accounts, ledgers or transactions to our servers merely because the device is connected to the Internet.

3. Supabase Authentication and User Management

SmartAccounts uses Supabase for application authentication and user-management functionality.

Information required for authentication and user management may include account identifiers, email address, phone number, role, account status and related profile information.

Supabase is used for authentication and authorized user-management operations. Customer accounts, ledger records and transaction data are not automatically synchronized to Supabase as part of normal business operations.

4. Google Drive Backup

SmartAccounts may provide an optional Google Drive Backup feature. This feature is used only when the user chooses to connect their Google account and create or restore a backup.

When the user connects Google Drive, Google authorization is used to allow SmartAccounts to access the application's private backup storage area in the user's Google Drive.

SmartAccounts uses the Google Drive appDataFolder storage area for application backups. This area is intended for application-specific data and is separate from the user's normal visible Drive files.

Google Drive access is not used to automatically synchronize customer accounts, ledgers or transactions continuously. It is used for the user's optional backup and restore operations.

5. Google Account Information

When Google Drive Backup is connected, SmartAccounts may display the Google account selected by the user so that the user can identify which Google account is connected for backup purposes.

SmartAccounts does not request access to the user's Gmail messages, Google Contacts, Google Photos or unrelated Google Drive files.

6. Backup Security

SmartAccounts uses encryption and password protection for application backup data before it is stored or transferred through supported backup mechanisms.

Backup files are intended to contain application data required to restore the user's SmartAccounts records. Authentication credentials, raw passwords, session tokens and similar security secrets are not included in the backup payload.

Users should keep their backup password secure. If a backup password is lost, the encrypted backup may not be recoverable.

7. Manual Backup

SmartAccounts provides a manual backup option that allows the user to create a backup file and save or share it using Android's available file-sharing mechanisms.

Manual backup files are created at the user's request. SmartAccounts does not automatically send manual backup files to third parties.

8. Restore

When a user chooses to restore a backup, SmartAccounts validates the backup and, where required, requests the backup password before restoring supported records to the local application database.

9. Data Sharing

We do not sell users' personal information.

SmartAccounts does not use customer ledger data for advertising, behavioral tracking or targeted marketing.

Information may be processed by service providers used for authentication or optional backup functionality, such as Supabase for authentication/user management and Google for Google Drive authorization and storage when the user chooses to use those features.

10. Advertising and Analytics

SmartAccounts is not designed to use customer ledger information for advertising or analytics.

The application does not intentionally collect customer business records for advertising or tracking purposes.

11. Data Retention and Deletion

Locally stored customer accounts, ledgers, transactions and settings remain on the user's device until they are deleted through the application, the application's data is cleared, or the application is uninstalled, subject to Android device behavior.

Optional Google Drive backups remain in the user's Google Drive until the user deletes them or removes them through supported application/account controls.

12. User Control

Users control whether they create manual backups or connect Google Drive for optional backup and restore.

Users may choose not to connect Google Drive and may continue using SmartAccounts with its local/offline functionality.

13. Children's Privacy

SmartAccounts is intended for business and account-management use and is not directed specifically to children.

We do not knowingly collect personal information from children for advertising or profiling purposes.

14. Security

We take reasonable technical measures to protect information handled by SmartAccounts. These measures include local data protection, authenticated access, encryption of supported backups and access controls appropriate to the application's functionality.

However, no electronic storage or transmission method can be guaranteed to be completely secure.

15. Changes to This Privacy Policy

We may update this Privacy Policy from time to time to reflect changes to SmartAccounts, its features or applicable requirements. The updated policy will be published at this same location with an updated "Last Updated" date.
